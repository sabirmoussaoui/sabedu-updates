# SABEDU updates

Official Windows release channel for SABEDU. This repository is reserved for installers and update information; application source code is kept separately.

No release has been published yet. SABEDU 1.0.0 does not include an update checker. The first updater-enabled version will require one manual installation; later versions can be checked and installed from inside the app.

School data and user settings stay on each user's computer and are not uploaded to this repository.
